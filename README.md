# mauriciokj.github.io

Blog pessoal em Jekyll para GitHub Pages.

## Estrutura

- `_posts/` — posts do blog
- `_layouts/` — layout base
- `assets/css/` — estilos
- `.github/workflows/jekyll.yml` — build/deploy no GitHub Pages

## Publicação

O deploy é feito pelo GitHub Actions ao dar push para `master` ou `main`.
